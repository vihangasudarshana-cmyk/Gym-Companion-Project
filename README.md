  Gym Companion & Workout Tracker

A modular, interactive Python terminal application designed to organise, track, and dynamically update gym training splits and recovery protocols.

  Features
- Categorised Splits: Pre-configured routines for Push, Pull, Leg, Cardio, Core, and Active Recovery.
- Dynamic Routine Creation: Allows users to add brand-new routines or append extra exercises into existing splits during runtime without overwriting existing data.
- Data Sanitation: Automatic string parsing and stripping to handle irregular user inputs and comma-separated lists.
- Interactive Menu Loop: Continuous command-line navigation with a safe exit condition.

  Built With
- Language: Python 3
- Data Structures: Dictionaries, Nested Lists, List Comprehensions
- Version Control: Git & GitHub
